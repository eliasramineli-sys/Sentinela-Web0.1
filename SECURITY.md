# Segurança

Este MVP não está pronto para distribuição pública ampla sem validação nativa e revisão independente. Não envie senhas, tokens, dados bancários ou URLs pessoais em issues públicas.

O repositório remoto e um canal privado de suporte ainda não foram definidos. Antes de publicar, o titular deve configurar o reporte privado de vulnerabilidades e informar um contato real. Não há endereço de e-mail fictício nesta entrega.

Para uma falha, prepare uma descrição mínima: versão, plataforma, comportamento esperado/observado e reprodução com domínio reservado. Não acesse alvos maliciosos, explore serviços de terceiros nem publique dados de vítimas para reproduzir um problema.

A versão 0.1 é o único alvo atual. Não há política de prazo de correção ou manutenção de versões antigas estabelecida.
